# Pyth Pro MCP server

The Pyth Pro MCP server moved to
[`pyth-network/pyth-lazer` `apps/mcp`](https://github.com/pyth-network/pyth-lazer/tree/main/apps/mcp).

Releases, the MCP registry entry (`server.json`), and the
`ghcr.io/pyth-network/mcp-server` image are published from that repository.

The MCP Skills that lived in `apps/mcp/skills` moved with the server to
`pyth-network/pyth-lazer` `apps/mcp/skills`.
