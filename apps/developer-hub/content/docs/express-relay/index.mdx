# Express Relay has been wound down

In July 2026, Pyth governance passed [OP-PIP-124: Express Relay Wind-Down](https://forum.pyth.network/t/passed-op-pip-124-express-relay-wind-down/2642). Express Relay is no longer an actively supported Pyth product; the auction service, SDKs (`@pythnetwork/express-relay-js`, `express_relay` Python), and on-chain `ExpressRelay` contracts are being retired.

**Existing integrators**: reach out on the [Pyth developer forum](https://dev-forum.pyth.network/) if you need migration guidance.

For Pyth's other products, see [Price Feeds](/price-feeds) and [Entropy](/entropy).
