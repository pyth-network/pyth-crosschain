date: 2026-08-05

New Pyth Pro users can now see what their plan includes, review a ready-to-run
API request for their key, and send that request directly from Pyth Terminal —
without leaving the app to piece together a curl command.

Why it matters: the fastest path to your first successful call is now built
in. Instead of assembling the endpoint, headers, and channel arguments by
hand, you can copy or execute the exact call that will work with your key,
and immediately see the response shape.

What to do: sign in to Pyth Terminal and open the onboarding walkthrough on
first launch, or revisit the getting-started guide at any time. Existing
integrations are unchanged.

- [Getting Started with Pyth Pro](https://docs.pyth.network/price-feeds/pro/getting-started)
- [Acquire an API Key](https://docs.pyth.network/price-feeds/pro/acquire-api-key)
