product: pyth-pro

The sponsored `SUIUSDE/USD` push feed on Sui mainnet is now available through
the Pyth Pro-compatible push-feed path. The underlying sponsored feed remains
listed on the Sui page with a 10-second heartbeat and 0.5% price-deviation
threshold.

**Why it matters:** Sui integrators can use the Pro-compatible feed path for
SUIUSDE while keeping the same sponsored-feed freshness model, instead of
treating SUIUSDE as a separate Core-only integration.

**What to do:** use the Sui push-feeds page to find the `SUIUSDE/USD` feed ID
and consume it through the Pro-compatible Sui push-feed path. Existing Core
feed integrations do not need to change.
